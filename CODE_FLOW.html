A통합시스템 시험

도구 = 출입통제 시스템(장치) 역할, 상대 = 통합플랫폼.
상대가 도구로 요청을 보내고, 도구는 응답을 만들어 돌려주면서 받은 요청을 채점합니다.

  • 관리도구 대상: INTEGRATED_SYSTEM
  • 화면·채점: platformVal_all.py
  • HTTPS 서버: api/server_thread.py + api/api_server.py
  • 쓰는 spec: Schema_request · Data_response · Constraints_response · validation_request

B단일시스템 시험

도구 = 통합플랫폼 역할, 상대 = 단일 시스템(장치).
도구가 요청을 만들어 보내고 상대 응답·웹훅을 채점합니다.

  • 관리도구 대상: PHYSICAL_SECURITY
  • 화면·요청·채점: systemVal_all.py
  • 웹훅 수신 서버: api/webhook_api.py
  • 쓰는 spec: Schema_response · Data_request · Constraints_request · validation_response
모드 결정: 시험 정보의 targetSystem을 한글 이름으로 바꾸고(ui/info_GUI.py:1540), 시작 시 "단일시스템"이면 systemVal_all, "통합시스템"이면 platformVal_all 화면을 엽니다(main.py:178~226).
